KIRI FITNESS｜一對一課程・一般新生首次訪談問題
==================================================

用途：第一次接受私人教練課程的新生。
建議方式：自然聊天，不必逐題照念；可依學生回答追問並做重點紀錄。
注意：本提綱不是 PAR-Q+，也不能代替正式的運動前健康篩檢或必要的知情同意程序。

學生姓名：____________________
訪談日期：____________________

一、運動動機與期待（建立信任、了解需求）
--------------------------------------------------
1. 當初是什麼原因，讓你想開始上一對一的課程？
2. 之前有考慮過自己運動，或是參加其他課程嗎？
3. 你希望透過這個課程，獲得什麼樣的改變？
4. 你對私人教練課程有什麼期待？或是有什麼比較擔心的地方嗎？

教練觀察：學生是希望有人督促、學習正確動作、改善體態，還是有明確的體能需求？
紀錄：


二、運動目標與成果期待（協助目標具體化）
--------------------------------------------------
1. 你目前最想改善身體的哪個部分？
2. 你比較在意肌力、體態、活動能力、體能，還是其他方面？
3. 有沒有什麼以前做不到、現在很希望自己能做到的動作或事情？
4. 如果三個月後回頭看，你覺得出現什麼改變，就會認為這段訓練很值得？
5. 有沒有特別想達成目標的時間？例如活動、旅行或比賽？

可追問：如果學生說「想讓體態變好」，是希望整體線條改善、增加肌肉，還是其他改變？
紀錄：


三、過往運動經驗與運動史（判斷起始程度、找出喜好）
--------------------------------------------------
1. 你以前有規律運動的習慣嗎？大概持續多久？
2. 之前接觸過哪些運動？例如重訓、TRX、瑜伽、跑步或團課？
3. 有沒有什麼運動是你特別喜歡，或特別不喜歡的？
4. 目前一週大概運動幾次？每次多久？通常強度如何？
5. 以前有沒有一段時間很認真運動，後來又中斷了？當時是什麼原因？

教練觀察：留意過去中斷運動的原因，例如工作安排、疲勞、強度過高或缺乏成就感。
紀錄：


四、生活型態與日常作息（了解恢復與訓練限制）
--------------------------------------------------
1. 平常工作大部分是坐著、站著，還是需要經常走動？
2. 一天大約會坐多久？平常活動量多嗎？
3. 平常睡眠狀況如何？大概睡幾個小時？
4. 平常工作或生活的壓力大嗎？
5. 最近會不會經常覺得疲倦，或是睡醒還是很累？
6. 平常的飲食有什麼習慣？例如常外食、用餐不固定？

教練觀察：主要了解生活負擔與恢復條件，不需在首次訪談中要求精細飲食紀錄。
紀錄：


五、身體狀況、傷病與健康史（運動安全）
--------------------------------------------------
1. 目前身體有沒有哪裡容易痠痛、不舒服，或特別需要注意的？
2. 以前有沒有受過比較嚴重的傷，或動過手術？
3. 有沒有哪個動作會讓你感覺疼痛，或是做起來特別不舒服？
4. 目前有沒有心血管、血壓、糖尿病或其他需要持續追蹤的健康狀況？
5. 最近有沒有在運動或日常活動時，出現胸痛、暈厥、異常喘不過氣或暈眩的情況？
6. 現在有沒有服用可能影響運動反應的藥物，或醫師曾提醒你需要注意運動強度？
7. 目前有沒有正在接受治療、復健，或是其他運動限制？必要時再詢問懷孕、產後等相關狀態。

教練提醒：搭配正式 PAR-Q+ 篩檢；如有運動相關警訊，先停止測試並依情況轉介醫療專業人員。教練不進行醫療診斷。
紀錄：


六、運動感受與教學偏好（建立個別化指導方式）
--------------------------------------------------
1. 你覺得自己現在運動時，最困難的事情是什麼？
2. 你喜歡比較有挑戰性的訓練，還是希望循序漸進、慢慢學會動作？
3. 你會比較喜歡教練詳細解釋每個動作，還是做的過程再慢慢調整？
4. 有沒有哪個動作你一直做不太好，或覺得很難理解？
5. 你通常怎麼判斷自己這次運動有沒有練到、練得好？

教練觀察：例如學生是否以大量流汗、痠痛或疲累作為訓練有效的唯一標準。
紀錄：


七、訓練安排與長期執行（建立可持續的習慣）
--------------------------------------------------
1. 如果希望養成規律運動，一週安排幾次對你比較實際？
2. 除了我們上課以外，你願意自己安排一些簡單的自主練習嗎？
3. 有沒有什麼事情可能會讓你無法持續運動？
4. 你比較希望教練用什麼方式幫助你維持運動習慣？
5. 如果課程中需要調整動作姿勢，你希望我先口頭引導嗎？必要時是否接受經你同意的肢體輔助？

紀錄：
